# V1 Master — funzioni incluse

- Due percorsi: **Crea da template** e **Crea da foto**.
- Template: Editoriale, Minimal, Highlight.
- Foto: Foto pulita, Frase breve, Pensiero, Dettagli grafici.
- Formati: 9:16, 4:5, 3:4, 1:1.
- Filtri: Originale, Acida Soft, Acida Warm, Neutro, con intensità.
- Banca frasi locale con ricerca, categorie, preferiti, usate/non usate, aggiunta singola, aggiunta multipla, import JSON/CSV/ZIP.
- Marcatura frase come “usata” **solo al momento dell’export**.
- Libreria sticker locale con 48 elementi iniziali, preferiti, aggiunta singola e import ZIP.
- Seconda immagine e fino a 5 livelli aggiunti, trascinabili, ridimensionabili, ruotabili, opacità e ordine avanti/dietro.
- Firma automatica Ironicamente Acida.
- Progetti modificabili: salva, riapri, duplica, elimina, esporta.
- Autosalvataggio bozza.
- Export PNG per template e JPEG alta qualità per foto.
- Web Share API quando disponibile.
- Backup contenuti e backup completo; ripristino locale.
- Nessun account e nessun server nella V1.
